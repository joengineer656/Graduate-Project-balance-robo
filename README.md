# Balance Robot – shared notes

`Balance Robot Vault/` is a separate Obsidian vault shared by the whole team through this repo
(Notes, Logs, Tasks, Attachments; Dataview + Tasks plugins included).

**Setup (once)**
1. `git clone https://github.com/joengineer656/Graduate-Project-balance-robo.git`
2. Obsidian → Open another vault → **Open folder as vault** → choose `Balance Robot Vault`.
3. When asked, click **Trust author and enable plugins**.

**Use:** write notes in the vault, then click **🔄 Sync with team** on `Home` (or run `./sync.sh`).
Sync often, so two people rarely edit the same lines. Pasted images go to `Attachments/` automatically.
